# Sicherheit und Datenschutz-Meldungen

Bitte melde Sicherheitslücken oder versehentlich veröffentlichte persönliche Daten **nicht** als öffentliches Issue,
sondern über **GitHub → Security → „Report a vulnerability“** (privater Bericht an die Maintainer).

Wir bestätigen innerhalb von 72 Stunden. Persönliche Daten entfernen wir aus dem aktuellen Stand sofort und aus der
Historie, sobald es technisch möglich ist.

Im Rahmen: Wege, wie Daten den Rechner ungewollt verlassen könnten; Schlüssel in Logs oder Dateien; Umgehung von
„Nur lokal“; Schwächen des Einrichtungs-Dialogs (127.0.0.1-Server, Token).
