# Pilot: XLRTE Mastery in zwei Wochen

Danke, dass du mitmachst. Du hilfst, XLRTE Mastery für viele andere besser zu machen. Rechne mit **30 Minuten Einrichtung**
und danach **10–15 Minuten pro Tag**, solange es dir nützt.

## Was du bekommst

- Ein Lern-Cockpit für deine Prüfung (oder eine eigene), mit ehrlicher Prognose.
- Jeden Tag neue Übungen aus deinem Paket und einen Tages-Recap am Abend.
- Einen Tutor-Prompt für deine KI, der aus deinem echten Lernstand arbeitet.

## Einrichtung (Mac, Windows, Linux)

1. Python 3.9 oder neuer installieren: <https://www.python.org/downloads/> (Mac: oft schon da, `python3 --version`).
2. Repository holen: grüner Knopf **Code → Download ZIP** auf GitHub, entpacken. Oder mit Git:
   `git clone https://github.com/token8/xlrte-mastery.git`
3. Im Ordner starten: Mac/Linux `./mastery`, Windows Doppelklick auf `mastery.cmd`.
4. Der Einrichtungs-Dialog öffnet sich im Browser. Wähle oben rechts Deutsch oder English. Zum Ausprobieren
   „Beispieldaten“ angehakt lassen.
5. KI anbinden: Wenn du ein Claude-, ChatGPT- oder Gemini-Abo hast, wähle die passende App. Ohne KI geht es auch.

## Zwei Wochen, ein Rhythmus

| Tag | Was du tust |
|---|---|
| 1 | Einrichten, mit Beispieldaten herumklicken, erstes Feedback (siehe unten) |
| 2–3 | Beispieldaten entfernen, eigene Daten anlegen |
| 4–10 | Täglich nutzen, Auffälligkeiten sofort als Issue notieren |
| 11–14 | Kurzes Abschluss-Feedback (5 Fragen) |

## So gibst du Feedback

- **Schnell:** GitHub → *Issues* → *Pilot-Feedback* (Formular, 2 Minuten).
- **Fehler:** *Issues* → *Fehler melden*. Bitte mit den Beispieldaten nachstellen, nie mit deinen echten Daten.
- **Ideen und Fragen:** *Discussions*.
- **Selbst verbessern:** Issues mit dem Label `good first issue` sind für den Einstieg gedacht. Pull Request genügt,
  Anleitung in [CONTRIBUTING.md](../CONTRIBUTING.md).

## Deine Daten

Alles bleibt auf deinem Rechner. Niemand sieht deine Daten, auch wir nicht. Schicke uns nie Screenshots mit echten Namen,
Firmen oder Notizen; die Beispieldaten reichen für jede Fehlermeldung.
